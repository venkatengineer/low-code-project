📦 Installation & Testing

To install directly onto Arch Linux Plymouth:

cd ~/Projects/solaris-bootsplash/plymouth-theme/solaris-alien-boot sudo ./install.sh

To test live in a window:

sudo plymouthd sudo plymouth --show-splash # Wait 8 seconds, then quit: sudo plymouth --quit
